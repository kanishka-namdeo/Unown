# Landing components (src/components/landing/)

## Purpose

Every band of the marketing page: the hero, the learning loop, the capability dex, mission control, the live demo gallery, the built & improved showcase, the proof panes, the Unown alphabet, the FAQ, the shipping rail and the finale — plus the shared primitives, effects and generated data they render. This doc is the authority on the page's structure, its palette, its honesty rules and its verification gates; the research behind the decisions is `docs/landing-research.md`.

## Ownership

- Owns: every file in `src/components/landing/` and this doc. The composition root (`src/app/page.tsx`), layout and stylesheets are the parent's (`src/AGENTS.md`); `src/components/ui/accordion.tsx` is the parent's vendored primitive.
- The tracked media under `public/landing/` (OG images, `creatures/`, `tui/`) is rendered by these components but captured/generated by the `scripts/` lanes — see `scripts/AGENTS.md`. Never delete or hand-edit media assets; regenerate through the owning lane.

## Local Contracts

**Structure — eleven bands, one file each, order is the argument:**

2. `loop.tsx` (leaf) — how it learns: three tabbed beats (Work/Learn/Dream), each body a literal gated artifact (note template from `termhooks.ts`, log lines from `harness.ts`, real memory lines) + the terminal-vs-engine pair strip rendering generated `ENGINE_JOBS`.
3. `dex.tsx` (magma) — the capability dex: one numbered spine, FRLG two-pane listbox (roving tabindex, selection follows focus, fuse.js search scoped to the active screen), screen selector, detail pane mounts ALL entries (inactive `hidden`), lazy posters (`data-poster`), **webm-first sources with a one-shot mp4 fallback on a media `error`** (a decode error on Chromium does not walk to the next `<source>`, and hardware VP9 decoders can reject these streams — the visible reel swaps to its `data-mp4` sibling once and resumes), synthesized Web-Audio cries (forms only), `#dex-<id>` deep links via `history.replaceState`, the `/split*` display-command table (its own gated `COMMANDS` array — `parseCommands` in the claims gate reads the FIRST `const COMMANDS`, so this file carries exactly one).
4. `showcase.tsx` (gold) — mission control: framed real `unown dashboard` PTY stills from `public/landing/tui/dashboard/stills/`, the twelve-surface `SCREENS` list, the addons strip (from `addons-data.ts`). Dashboard affordances point at in-page anchors only — the web dashboard is retired (D7).
5. `live-demo.tsx` (aqua) — the agent-built apps, running live: a switchable GALLERY (the commerce round, the v0-templates pattern — one live deployment per artifact). Each app iframes its own route in browser chrome: `/demo` (Sigil Focus — `docs/live-demo-session.md`), `/bazaar` (Sigil Bazaar — `docs/bazaar-demo-session.md`), and `/cadence` (Cadence — `docs/cadence-demo-session.md`), one persistent iframe whose src swaps on the switch (a same-origin navigation, never a remount). A working per-app reset (postMessage handshake `{source: "unown-landing", type: "<app>-reset"}` — `sigil-reset` / `bazaar-reset` / `cadence-reset` — the demos listen for in embed mode; the landing pins `targetOrigin` to `window.origin`, NEVER `"*"`), a full-screen escape hatch per app, and receipt chips that swap with the tab (from `live-demo-data.ts`, the addons-data pattern — counts pinned by test, receipts in each app's session record). Below `sm` the frame is replaced by the active app's poster + a tap-through link to its route — a 390px iframe of a storefront is a punishment, not a demo (all three apps collapse to tabs/sheets there). The apps live in `src/app/demo/` + `src/components/sigil/` + `src/lib/sigil/`, `src/app/bazaar/` + `src/components/bazaar/` + `src/lib/bazaar/`, and `src/app/cadence/` + `src/components/cadence/` + `src/lib/cadence/` (route-scoped stylesheets in each route's `globals.css`; the landing page never downloads either). All three demo routes carry CSP `frame-ancestors 'self'` + `X-Frame-Options: SAMEORIGIN` (`next.config.ts`); the bazaar order POST and the cadence checkoff POST are rate-limited per IP (per-lambda-instance semantics). Contrast rule learned the hard way: NO translucent text/background tokens on the chrome bar — axe computes the effective contrast THROUGH alpha (`bg-ink/15` read 1.73:1); opaque pills on full-strength tokens only.
6. `built-improved.tsx` (gold) — "Built & Improved With Unown" (2026-10-29; rebuilt for the SOTA round the same day): the mission's showcase deliverable, the receipts layer OVER the gallery — while the gallery shows what the agent BUILT running live, this band shows what its learning loop produced during the build, receipts first. Drift-pinned by `__tests__/built-improved.test.tsx` (the exact title, the tally rows' figures + bodies, stills on disk with true IHDR dims, the three links, and the number drift pin: every number in the band's data re-extracted against the test's literal set — the live-demo pattern).
7. `proof.tsx` (magma) — one tabbed band, three panes (Benchmarks / Integrity / Models), all panes stay mounted with `hidden` so generated numbers stay in the SSR DOM for crawlers and gates.

The band's exit ("the full record") links CHANGELOG.md, GitHub Releases and the blog — the longhand lane of the same record.
11. `finale.tsx` (leaf) — the last ask + the `Spellbox` toy, CTA links, Konami receipt.

`effects.tsx` also owns the presence round (2026-10-28): `DecodeText` (the kicker's one-shot UNOWN decode wave — pixel font only, monospaced = zero CLS; SSR ships the finished line; the wave runs post-hydration and self-clears; the pure scheduler `decodeLockTick`/`decodeCharAt` is pinned by `presence.test.tsx`), `SpotlightProvider` (ONE passive document-level `pointermove` listener writing `--mx`/`--my` on the hovered `[data-spotlight]` element only — never a global var, the tier-list "inheritance bomb"), `useScrollSpy` (the nav's `aria-current="true"` marker — a state, not motion; ships under reduced motion; hero and finale mark nothing), and `CountUp` (receipt figures that count once on first view; the DOM ships the final figure, intermediate frames are animation artifacts, `0/50`-style ratios render immovable). **The carving round (2026-10-28) adds `DrawGlyph` + `useGlyphReveal` (pure `glyphRevealAt` pinned by `carving.test.tsx`)** — the driver for `Glyph`'s long-unwired `reveal`/`drawStagger` stroke contract: SSR ships the finished glyph (`reveal` starts at 1, a resting form renders plain paths with NO dash ladder), an IntersectionObserver arms the first draw when the glyph actually enters view, and every id change replays it — user-initiated by construction on both wirings (the decode panel's hover/pick, the spellbox's typing; the spellbox passes `ms={380}`). Reduced motion never starts the rAF; a missing IntersectionObserver is a no-op (the finished glyph). Drawn glyphs are decorative (`aria-hidden`) — the Latin text beside each is the accessible reading. Wired in `alphabet.tsx` (the decode panel's subject) and `finale.tsx` (the spellbox letters, inside their motion.span fade-rise — the two motions layer like the loop beats). `shell.tsx` owns the shared chrome (`Nav` + `NAV_ENTRIES`: every entry in page order, tagged `primary` (the four argument links — How it learns, Capability dex, Proof, FAQ) or `more` (the six record surfaces — Dashboard, Live demo, Built & Improved, Alphabet, Changelog, Blog) which fold behind the desktop `NavMore` disclosure; the below-`lg` section menu renders all ten flat, never nested — path-refs render through next/link, anchors stay plain `<a>`; the `BetaBadge` the header wordmark and the hero kicker both render (one component, two badge homes; the footer's "Currently in beta." line is the third, word-only — the wordmark carries no tagline, the H1 says it); `Footer`, which takes an optional `anchorPrefix` so the blog routes can render it with its in-page anchors resolving to the landing page, and whose link grid carries the eighth cell — the `/blog` link; `ThemeToggle` auto→light→dark persisting `unown-theme`; `TerminalWindow`; links; `SectionHead`; hue/tone helpers). `effects.tsx` owns `LandingStyles` (the `<noscript>` restore that undoes framer's inline `opacity:0`), `LetterRainProvider`, `AlphabetWakeProvider`, `useKonami`. `LandingMotion` (shell.tsx) is the ONE place framer reduced-motion is handled (`reducedMotion="user"`).

**Authored data (hand-maintained):** `dex-data.ts` (append-one-object `RAW`; numbers stamped from array position — never typed; `Capture` = video|still|pending with `PENDING` the honest empty stage), `faq-data.ts`, `lexicon.ts` (28 entries; `lore` verified against Bulbapedia/PokemonDB/Wikipedia/ssbwiki only; `means` a DECODE <= ~12 words, never a spec), `addons-data.ts` (mirrors `addons/config.ts` leaf keys — the test suite drift-pins it), `benchmarks.tsx`'s derived `LIFT_SCALE`/`COLD_BAR_W`.

**Creatures and glyphs:** `creature.tsx` renders the feature creatures (authored pixel art — never Pokemon assets, never a named species; decorative by default, height-locked to 64px multiples, `image-rendering: pixelated`); the sprites under `public/landing/creatures/` are written by the deterministic pipeline (`scripts/creature_*.mjs` — the script is the art). `glyphs.ts` holds the 28 hand-authored Unown stroke-path forms; `glyph.tsx` renders them with palette tokens via CSS vars — no hand-picked hexes (that is what keeps `gba_palette_check.mjs` honest). **Vendored:** `provider-marks.tsx` is generated from pinned CC0 Simple Icons by `scripts/vendor-provider-marks.mjs` — never hotlink, never `npm i simple-icons`; OpenAI/Agnes/llama.cpp are text-only by design.

**Honesty rules (the page is part of DOX):** every number is checkable against a committed receipt; suite names by path, never counts; unmeasured figures print "not measured"; the page says plainly it is an independent project (the Footer notice); no `aggregateRating` in the JSON-LD (`seo.tsx`); a claim that contradicts the code is the same defect as a stale doc line — cut the claim, never invent a replacement figure.

**Motion and a11y:** the base state of every animated rule is the finished state (reduced-motion = everything renders complete); reveal animations animate `transform`/`scaleX`, never `width`; only user-initiated playback is announced; tabs/listboxes follow WAI-ARIA patterns with roving tabindex; exactly two live regions on the page. The presence round (2026-10-28) adds its own wiring rules: the H1's words settle via CSS `.word-settle` with inter-word spaces in the PARENT inline flow (a space inside an inline-block is browser-collapsed, and h1.textContent must stay character-exact for the copy/SEO/deploy gates); the `.route-bar` (scroll progress) is `aria-hidden`, `@supports (animation-timeline: scroll())`-gated, 3px, and NOT rendered under reduced motion; `.pane-swap` (the 160ms three-frame tab settle) rides `display:none -> block` animation restarts — panes stay mounted/`hidden`, the DOM contract is untouched; the CTA glint (`.gb-btn::after`) is hover-gated `steps(4)`; the demo chrome's `Live` chip is an opaque pill on full-strength tokens (the gallery round's axe lesson) with an `aria-hidden` blinking square; and the live-demo frame NEVER carries `data-spotlight` — a tint following the cursor into an app the visitor is operating is not feedback. The route bar's height is 3px because the Agnes VLM review read the 2px cut as too subtle to read as functional — the decision and its reviewer are recorded here. **The carving round (2026-10-28) adds its own rules:** `.ink-fill` (the decode fill on a `SectionHead` lead with the `decode` prop — wired only in the finale) animates COLOR between two AA palette text tokens (`faint` → `dim`), never opacity — an Apple-style 40%-alpha frame would fail the axe contrast gate this page runs in both motion passes, and AA-at-every-frame is the only honest spelling here; its per-word stagger caps at `INK_FILL_MAX` (8, exported from `shell.tsx`) so any lead length fits inside `entry 100%`; the word-split keeps inter-word spaces in the parent inline flow and textContent byte-identical (the word-settle rule). `.gb-kbd` keycap chips spell the Konami sequences in the MONO face only (Press Start 2P's latin subset carries no ↑↓←→ — the same reason every `▶` is drawn as SVG), compacted to BetaBadge-proportioned metrics after the Agnes VLM round caught the first cut growing its host line; the chips are NOT aria-hidden (the alphabet hint is how a screen-reader user discovers the egg). `CopyButton` carries an sr-only `role="status"` "Copied" region (WCAG 4.1.3 — the icon swap alone is silent); the dex band's "exactly two live regions" pin is untouched because no copy button lives there. ## Work Guidance
