## The measurement-confound receipt (a validation-log-class lesson)

A2 reported the root battery as "2353 pass / 3 fail / 2356 tests / 177 files" and stash-verified the 3 fails as pre-existing. The operator's re-run with the CORRECT command (`bun run test:unit` = `bun test src --path-ignore-patterns=data/self-learning/**`) shows **2353/0/172 — GREEN**. The confound: A2 ran bare `bun test src`, which collects engine-minted fixtures under `data/self-learning/**` — the EXACT pitfall recorded in project memory ("a family-baseline test pollution pitfall… the verified fix is the --path-ignore flag"). A2's stash-verify discipline could not catch it because the wrong command was used on both sides of the stash. LESSON (the receipt): acceptance items name the SCRIPT (`bun run test:unit`), never the bare command — and a "pre-existing failure" claim inherits the measurement's validity. The nocturne/encore/iframe "failures" were engine-data fixtures, not code.
