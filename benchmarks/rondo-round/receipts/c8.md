## The flake catch (the round's second §5-class reflection, and the gate doing its job)

runs, no dishonesty). The operator's interleaved cross-runs caught
the battery NOT stable: **12/14, 13/14, 11/14, 12/14** — the
[REFUSED] lane hung the full 60 s at `waitForEvent("filechooser")`
on cold/first-in-a-while boots, and the serial worker skipped
[REFRUPT]/[CORRUPT] after it. Root cause (reconciled from A2's
narrative + the operator's code read): the pre-fix `triggerImport`
had (a) a flat 50 ms wait for the app's hidden-input removal — on a
cold CDP channel the async `onchange` handler outlives it, leaving a
stale input whose in-flight handler races the next press's chooser
event; (b) no retry arm — a single missed event = a 60 s hang.
**Honesty note (the operator's reconciliation): A2's root-cause
narrative claims the pre-fix wait was registered AFTER the keypress —
the pre-fix code the operator read had the correct order (the wait
was first); the load-bearing defects were the 50 ms guess + the
missing retry/fail-fast arm. The narrative's order claim is a
confabulation the receipt corrects; the FIX is correct regardless.**

The fix (the C-2 fake-clock law applied to the filechooser):
DOM-condition waits (the input's detachment), a 15 s bounded retry
window with a 3 s per-attempt race, fail-fast with a state dump on
expiry (input count, notice text, SW controller flag — a bounded
honest failure, never a hang). The raised stability bar (6 runs,
mixed cold/warm) then held on BOTH lanes (A2's 6/6 + the operator's
6/6 = 12 consecutive green, 6 of them cold boots).
