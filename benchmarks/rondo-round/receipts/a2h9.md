## Root cause — the chain

1. **The substring-filter blind spot (operator-side, verified).** `bun test src` does not mean "the src/ directory" — bun treats its path argument as a SUBSTRING FILTER on test-file paths. The battery's 161 files = the 145 test files under `src/` **plus** 16 test files under `apps/coda/src/` (6) and `apps/ostinato/src/` (10), whose paths also contain "src". Every green subset from the elimination map ran only `src/` files — the apps suites were never in it, which is why the 145-file walk-order re-derivation came up 16 short.
   - The 16 files (receipted, `bun run test:unit 2>&1 | rg "^apps/" | sort -u`):
     `apps/coda/src/domain/{boards,boundary,markdown,notes,search,tasks}.test.ts` and
     `apps/ostinato/src/domain/{boot,boundary,io,scheduler,stats}.test.ts` +
     `apps/ostinato/src/ui/{el,palette,queue-nav,runner-core,settings-modal}.test.ts`.
2. **The polluter: `apps/ostinato/src/ui/settings-modal.test.ts` (the R-2 deck-settings modal landing).** It renders the app's real `renderSettingsForm` (raw DOM, `document.getElementById`/`querySelector` — NOT React Testing Library) into the shared happy-dom `document.body`. Each of its 5 pins calls `cleanBody()` (`document.body.innerHTML = ""`) at the START of the test, so no residue exists mid-suite — but the LAST pin leaves the overlay + its `<h2 id="ostinato-settings-title">Deck settings</h2>` in the document when the file ends (no RTL auto-cleanup in this file, no `afterAll`).
3. **The mechanism (pinned by minimal repro).** In bun's one-process battery the document is shared across files. The leftover ostinato `<h2>` (verified: `document.querySelectorAll("body h2")` → `h2count=1 texts=Deck settings` after the settings-form render, no cleanup) coexists with the encore Finale's own level-2 heading when `encore.test.tsx` runs later in the walk → `getByRole("heading", { level: 2 })` throws "Found multiple elements with the role 'heading'" (the exact failure signature captured in the battery).
4. **The baseline-drift explanation.** The Etude baseline (2235 tests / 0 fail) predates the R-2 landing; the Rondo baseline (2257/1 at `18e4a98a`) postdates it — R-2 added 23 tests AND the polluting suite in one change.

## The fix (isolation at the polluting layer, product code untouched, encore assertions byte-identical)

`apps/ostinato/src/ui/settings-modal.test.ts`:

```diff
-import { test, expect } from "bun:test";
+import { afterAll, test, expect } from "bun:test";
...
   test("zero-deck honest empty state: decks [] → error lane shows the N hint", ...) { ... }
+
+  /** A2H-9 isolation: every pin renders the settings form into the
+   * shared happy-dom document.body WITHOUT RTL (and RTL's cleanup does
+   * not run in this file), so the overlay + its <h2> title outlive the
+   * suite and pollute the one-process battery — the encore Finale's
+   * `getByRole("heading", { level: 2 })` then finds this leftover
+   * heading alongside its own. Each pin's cleanBody() resets between
+   * tests, so this afterAll removes only the residue the LAST pin
+   * leaves behind. Lane A (DOM-free) skips it. */
+  afterAll(() => {
+    document.body.innerHTML = "";
+  });
```

The `afterAll` sits inside the `else` (DOM-present) branch, so Lane A (`cd apps/ostinato && bun test`, no DOM → the `!hasDom` skipped-stub branch) never executes it. Lane A confirmed green post-fix. The encore test file was NOT touched.
