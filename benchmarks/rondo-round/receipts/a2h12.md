# A2H-12 — Chaconne runner CLI guard fix (B-20)

STATUS: COMPLETE

## Root cause

`apps/chaconne/runner/index.ts` guarded its CLI entry (`main()`) with:

```ts
const isMain = (() => {
  try {
    return process.argv[1] !== undefined && path.resolve(process.argv[1]) === path.resolve(import.meta.url);
  } catch {
    return false;
  }
})();
if (isMain) main();
```

The comparison mixed two different namespaces: `path.resolve(process.argv[1])` is a
filesystem path (the script's real path), while `path.resolve(import.meta.url)` receives
a `file://` **URL string** — `path.resolve` has no URL awareness and treats it as a
relative literal, yielding `'<cwd>/file:/' + '/path/to/runner/index.ts'`. The two
strings can never be equal, so `isMain` was **always false** and `main()` never ran:
every `bun apps/chaconne/runner/index.ts run …` invocation silently exited 0 doing
nothing.

Live proof: a 4-line script performing the same comparison prints `equal? false`
(operator-verified before this fix). The C-6 e2e battery caught it as the first real
CLI invocation (`expect(out).toContain('run 2')` received `''`).

## The fix (one surgical change, guard region only)

Replaced the broken `isMain` IIFE with Bun's native `import.meta.main` — true only
when this module is the entry point, exactly the semantic the guard wanted; false in
the import lane (`import { cmdRun } from "./index.js"`), so tests stay unaffected.

```diff
 // The module is both a CLI entry and an importable core: run main only
 // when executed DIRECTLY (`bun runner/index.ts`), not when imported by
 // the test lane (`import { cmdRun } from "./index.js"`).
-const isMain = (() => {
-  try {
-    return process.argv[1] !== undefined && path.resolve(process.argv[1]) === path.resolve(import.meta.url);
-  } catch {
-    return false;
-  }
-})();
-if (isMain) main();
+// import.meta.main: true only when this module is the entry point
+// (the URL-vs-path argv[1] comparison was broken — path.resolve on a
+// file:// URL string yields '<cwd>/file:/...', isMain was always false).
+if (import.meta.main) main();
```

`git diff apps/chaconne/runner/index.ts` shows ONLY this hunk — no other runner
files, no app code, no e2e changes.
