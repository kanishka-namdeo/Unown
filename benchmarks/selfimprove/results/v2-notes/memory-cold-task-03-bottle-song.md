## Conventions
- Bottle-song output: pluralize "bottle" → "bottles" when count ≠ 1
- Bottle-song output: capitalize first word of each verse
- Bottle-song output: blank line between verses only (not after final verse)

## Known pitfalls
- Pluralization edge cases: 0 uses "bottles", 1 uses "bottle", 2+ uses "bottles"
- Capitalization must apply to every verse start, not just the first line
