## What was built (the CANARY artifact, in-repo + live in the operator lane)

**`scripts/a1/a1-dispatch.py`** gains the claim gate, wired BEFORE any
engine spend:

- **The ticket extraction**: `TICKET <X>-<n>` from the brief text (the
  standing brief shape carries it in the first line). No ticket →
  immediate proceed (zero overhead — the SHOULD-NOT law).
- **The claim-state read**: `git fetch origin` + `git log
  --format=%cI %s origin/main -80` parsed for `<ticket> CLAIMED
  (ACTIVE)` vs `<ticket> CLOSED` commits (the claim protocol's own
  medium — the ledger IS the git log). A claim not followed by a
  close, younger than `--claim-expiry` (default 45 min, the V-9
  window), **refuses the dispatch with exit 7 (CLAIM-CONFLICT)** and
  the stand-down instruction (the ledger-arbiter law, now enforced at
  the only point that saves turns).
- **The `--own-claim` exception**: the claiming lineage's own chunk
  chain proceeds (the gate must never deadlock the claimer's own
  continuation chunks).
- **The `--dry-run` lane** (the accidental-spend cure): prints the
  resolved command + the gate verdicts and exits without dispatching.
- **Best-effort transport law**: a fetch failure NAMED, never silent,
  never bricks dispatches (the offline lane still works).
