# Research R6 — Amp & Cursor CLI vs. Unown (competitive sweep)

**Date:** 2026-10-25 · **Agent:** amp-cursor-researcher · **Method:** direct fetches of official docs (ampcode.com/docs, cursor.com/docs `.md` endpoints, code.claude.com/docs, google-gemini.github.io/gemini-cli, openai/codex repo) — ~70 fetches; every capability below was verified against the live docs on that date. Unown counterparts verified in `/home/z/my-project/Unown/pi-repo/packages/{self-learning,tui,coding-agent}/src`.

**Amp state (big change):** ampcode.com/how-to + /manual have been superseded by **ampcode.com/docs** (`/docs` = Introduction). Amp is now "a coding agent and development environment built for the frontier": threads + **Orbs** (per-thread cloud machines) + **Runners** (your own machines as remote executors) + macOS/iOS apps + multiplayer/Space voice calls + plugin/skill Git repositories. The old "trust prompt" is gone — Amp now runs tools **without asking for approval** (policy is delegated to plugins/enterprise).

**Cursor CLI state:** the binary is **`agent`** (installed by `curl https://cursor.com/install | bash`; `agent acp` is the hidden ACP server). Reference docs live at `/docs/cli/reference/*` (parameters, slash-commands, permissions, configuration, output-format, terminal-setup, authentication). The flags the task brief hypothesized (`--message`, `--session`, `--retry`, `--async`, `--request-id`, `--foreground`, `--foreground-always`) **do not exist** in the current public CLI — do not implement against them. `request_id` appears only as a *field* in `--output-format json|stream-json` results plus `/copy-request-id`; checkpoints are IDE snapshots + CLI `/rewind`, not a `--checkpoint` flag.
