# Self-learning engine (pi-repo/packages/self-learning/)

## Purpose

Unown's core transformation: the self-learning layer that turns the vendored pi coding agent into an agent that finds its own weaknesses, fixes them, and remembers what worked. Implements the five mechanisms: tiered memory (`memory.ts`), self-improving harness with statistical ship gate and retention auto-unship (`harness.ts`), routing/background jobs (`router.ts`), AutoDreaming with canary gate + dream-minted Agent Skills (`dream.ts`, `skills.ts`), and 6-layer hooks (`hooks.ts`, `termhooks.ts`). Task minting (`mint.ts`) keeps the harness fed: real failures (or, when the suite saturates, LLM-authored harder curriculum variants) become new capability-eval tasks that graduate into the regression suite once passing. Also provides the `unown` terminal agent (`cli.ts`, `term.ts`, `tools.ts`) and the REST+SSE API the dashboard consumes (`server.ts`).

This package is Unowned (modified from upstream pi-mono); sibling packages (`ai`, `agent`, `tui`, `server`, …) are upstream code — their rules live in `pi-repo/AGENTS.md`.
