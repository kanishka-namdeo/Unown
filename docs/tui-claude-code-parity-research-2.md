# The Claude Code touch study, round 2 — the Da capo research (2026-11-16)

> Purpose: the second reverse-engineering sweep of Anthropic's Claude Code terminal experience, one day after the Toccata round shipped (v0.0.68, [`docs/tui-claude-code-parity-research.md`](tui-claude-code-parity-research.md)). Da capo — the theme from the head, played again — this round re-sweeps the same surfaces against NEW evidence: the official docs at their current shape (fetched 2026-11-16), the complete v2.1.300→v2.1.325 changelog delta, the community/niche catalog (statusline ecosystem, tweakcc, claude-chill, HN/Reddit threads), and the late-2026 sibling landscape (Codex 0.169 "terminal workspace", Gemini CLI's Antigravity successor, opencode V2, Crush v0.101, Amp CLI-only pivot). Verdict up front: **round 1 closed the input-history, draft, transcript, dialog and personality lanes — what the new evidence proves is a second gap cluster: the terminal-title state lane (a title is written but it never says what the session is DOING), the statusline script contract (the single largest community ecosystem around any CC surface, absent here), the redraw recovery lane, the external-editor context toggle, paste-pill search, invisible-character sanitization, and a six-command tail (/color, /keybindings, /tui, /copy [N], /terminal-setup, /statusline).**

Related: [tui-claude-code-parity-research.md](tui-claude-code-parity-research.md) (round 1, the A1–A16 decisions) · [usage](usage.md) · [dacapo-round-session](dacapo-round-session.md) (the session log)

## 1. The evidence base (every claim sourced)

### 1.1 The official interactive-mode reference, re-fetched 2026-11-16

`code.claude.com/docs/en/interactive-mode` (docs.anthropic.com 301-redirects there; fetched as markdown). Rows round 1 did not have or got refined:

- **Ctrl+L — "Redraw the screen": "Forces a full terminal redraw, keeping input and conversation history. Use this to recover if the display becomes garbled or partially blank."** Round 1 recorded Unown's ctrl+l as the model-selector fork move but logged no redraw lane at all — the recovery gesture itself is missing.
- **Ctrl+G / Ctrl+X Ctrl+E — "Open in default text editor"** with the `/config` toggle **"Show last response in external editor"**: "prepend Claude's previous reply as `#`-commented context above your prompt; Claude Code strips the comment block when you save" (also `Ctrl+X Ctrl+E` as the readline-native alias). Unown has Ctrl+G but no context toggle.
- **Ctrl+T — "Toggle Claude's task checklist"** — up to 5 tasks shown in the status area, restored expanded on `--resume` if left open; NOT the background-task view. (Unown: ctrl+shift+t collapse key — the fork move stands, documented.)
- **Ctrl+S — stash/restore now documents that a stashed `!` shell command "comes back in shell mode"** — mode included in the snapshot. (Unown's A4 snapshot already carries mode.)
- **Tab — "Accept an autocomplete suggestion, or add a comment to a permission answer"** — the dual role is now official (round 1 shipped both halves).
- **Esc on a permission prompt declines ("the same as No without a comment"); Esc+Esc clears a draft with text, opens the rewind menu on empty.** (Parity held from round 1.)
- **Ctrl+Enter or Ctrl+X Ctrl+S — send queued messages now** ("In terminals that don't report extended keys, Ctrl+Enter arrives as plain Enter; Ctrl+X Ctrl+S works in any terminal"). Unown's alt+s serves the any-terminal role.
- **Shift+Tab cycle now includes `bypassPermissions` and `auto` "where available"** + `Alt+M` on Windows when the runtime doesn't enable VT input. Unown's 3-mode cycle stays the deliberate divergence (round 1's correction register).
- **Transcript viewer keys**: the official table now carries `?`, `{`/`}`, `[`, `v`, `q`/`Ctrl+C`/`Esc` — plus, from `fullscreen.md`: `/` search + `n`/`N`, `j`/`k`, `g`/`G`, `Ctrl+u`/`Ctrl+d`, `Ctrl+b`/`Ctrl+f`/`Space`/`b`. Round 1's A9 shipped every one of these.
- **Text editing**: the full readline set is official and "not remappable via keybindings.json" (`Ctrl+Y`/`Alt+Y` paste history, `Alt+B`/`Alt+F`, `Alt+D`, `Ctrl+W` "one press removes a whole path or `--flag=value`"). Unown's editor matches the remappable parts (tui keybindings) and the Ctrl+W path semantics (round 1 item 5, E*).
- **Multi-line input**: `\`+Enter, Option+Enter, Shift+Enter, Ctrl+J, paste mode — parity held (item 1).
- **Reserved keys**: Ctrl+C, Ctrl+D, Ctrl+M (=Enter), Ctrl+[ (=Esc), Ctrl+I (=Tab), Ctrl+H (backspace byte), Caps Lock are unrebindable in CC. Unown's equivalent hard lanes (submit/interrupt/exit) match in spirit.

### 1.3 The official command/CLI surface, re-fetched 2026-11-16

`code.claude.com/docs/en/commands` (note: `/docs/en/slash-commands` now serves the skills page — the command table moved to `/docs/en/commands`), `cli-reference`, `terminal-config`, `statusline`. Commands round 1 did not catalogue:

- **`/statusline`** — "Configure Claude Code's status line. Describe what you want, or run without arguments to auto-configure from your shell prompt". The settings object: `statusLine: { type: "command", command, padding, refreshInterval ≥ 1s }`; the script reads a JSON payload on stdin (model, workspace incl. git worktree, cost incl. `total_lines_added/removed`, `context_window.used_percentage` + `exceeds_200k_tokens`, `rate_limits.five_hour/seven_day/spend_limit`, session id/name, `transcript_path`, version, `output_style.name`, `vim.mode`, `agent.name`, PR fields, `worktree.*`) and runs on session start + assistant message + /compact + mode change + timers (300 ms debounce, in-flight runs cancelled); output may be multi-line, ANSI-colored, OSC-8 clickable. **Configuring one suppresses most footer keyboard hints.**
- **`/color [color|default]`** — "Set the prompt bar color for the current session" (red, blue, green, yellow, purple, orange, pink, cyan; syncs over Remote Control; also works in `-p`).
- **`/keybindings`** — "Open your keyboard shortcuts file" (`~/.claude/keybindings.json`).
- **`/tui [default|fullscreen]`** — "Set the terminal UI renderer and relaunch into it with your conversation intact… With no argument, prints the active renderer".
- **`/copy [N]`** — "Copy the last assistant response to clipboard. Pass a number N to copy the Nth-latest… When code blocks or blockquotes are present, shows an interactive picker… Press `w` in the picker to write the selection to a file instead of the clipboard".
- **`/focus [on|off]`** — the focus view (only available in fullscreen rendering; shows only your last prompt, a one-line tool-call summary with edit diffstats, and the final response). Round 1 deferred; see §3.
- **`/terminal-setup`** — installs a Shift+Enter keybinding for VS Code/Cursor/Devin/Alacritty/Zed, enables Option+Enter in Apple Terminal, clipboard access in iTerm2.
- **`/recap`** — "Generate a one-line summary of the current session on demand" + automatic recap after ≥3 min away + ≥3 turns, capped at 400 chars (R16's precedent — Unown's /recap exists on demand; the refocus lane is the delta).
- **`/release-notes`**, **`/powerup`**, **`/scroll-speed`**, **`/sandbox`**, **`/effort [level|auto|status|ultracode]`**, **`/plan [description]`**, **`/model`** (`s` = session-only, Left/Right effort, "More models" grouping), **`/usage`** (`f` applies fixes), **`/output-style`**, **`/restart`** (alias `/update`).
- CLI flags of note: `--verbose` (overrides `viewMode`), `--ax-screen-reader`, `--bare`, `--safe-mode` (disables status line, custom themes, custom keybindings).

### 1.4 The community/niche catalog (fetched 2026-11-16)

Every source fetched in full unless noted. The load-bearing findings:

- **The statusline is an ecosystem, not a feature**: `ccstatusline` (13.6k★, 30+ widgets, powerline, TUI config), `CCometixLine` (Rust), `claude-powerline`, Claude HUD, `cc-probeline`, `fuelgauge`, Claudoro (a full Pomodoro app in the statusline). The payload contract is community-documented down to field level (`model.display_name`, `context_window.used_percentage`, `cost.total_cost_usd`, `workspace.current_dir`, `rate_limits.*.resets_at`). Complaints to design against: a custom statusline hides footer hints; slow scripts lag the bar (Rust rewrite = 20×); multi-line output corrupts on narrow terminals. Sources: `dandoescode.com/blog/claude-code-custom-statusline`, `aihero.dev/creating-the-perfect-claude-code-status-line`, `github.com/sirmalloc/ccstatusline`, `github.com/hesreallyhim/awesome-claude-code` (Status Lines section), r/ClaudeAI 1mlhx2j.
- **The flicker complaint is the #1 community pain** (claude-chill hit 192 HN points; `anthropics/claude-code#769` frames it as accessibility/photosensitivity; `blog.tymek.dev/claude-code-flickering-in-tmux`): never redraw whole screen for status changes. Unown's differential renderer already honors this — the Da capo lanes must not regress it (the statusline row renders through the normal component pipeline, not raw writes).
- **Destroyed scrollback / uncopyable output** is pain #2 ("I just want the exact same interface as the CLI, but with infinite scroll" — HN 47004712). Unown's regular-mode stream + fullscreen `[` scrollback write already answer it.
- **Spinner internals** (tweakcc README + HN 47004712): glyphs `· ✢ ✳ ✶ ✻ ✽` at ~120 ms, shimmer sweep 3 cells/50 ms while requesting; verbs were Haiku-generated per input (~1¢/day) then replaced with the static pool; "Gittifying…" scares users → verbs must be configurable (round 1 A15 shipped replace-mode config; CC's settings shape adds `mode: append`).
- **Notifications**: `preferredNotifChannel` = `iterm2|kitty|ghostty|terminal_bell` (official terminal-config.md); the community adds **OSC 777** (title;body) as the Ghostty/iTerm2/rxvt toast lane (`keyhell.org/posts/2026-03-26-claude-code-cli-notifications`, `anthropics/claude-code#92830`), and wants "needs input" distinct from "done" (issue #73384; the Stop-hook chime false-positives on subagent stops — HN 48745590).
- **Microcompact** is NOT a UI mode — it is silent context pruning (`[Old tool result content cleared]`, `keepRecent=5`, `clearAtLeastTokens=20000`, `DISABLE_MICROCOMPACT=1` requested in `#42542`, `#98204` reverse-engineered it, `#109283` documents the Desktop app setting it). No display mode to adopt; the pain point (silent trimming) is Unown's tiered-compact notices' to lose.
- **Paste pills**: `[⧉ …]` / `[Pasted text]` pills wrap multi-line pastes, Backspace deletes whole, Ctrl+R searches inside (2.1.314). The "⏎ newline marker" claim could NOT be verified in any source — the documented markers are the pills (round 1's Unown form `[paste #N +123 lines]` is the equivalent, stays).
- **"Tab to collapse" diffs — UNVERIFIED** in any current official or community source (round 1's recollection corrected; chevrons/click are documented).
- **Tabs/splits in the CLI TUI — do not exist**; "tabs" means tabbed dialogs; splits are tmux teammates and mod panes. No `/tabs` command to mirror.
- **tweakcc** (2.6k★) patches themes, input-pattern highlighters, banner/logo removal, table format, shimmer settings — evidence the theming surface matters; Unown's live-preview theme picker + settings hub already cover the legitimate subset.
- **i18n/IME edge cases** are real complaint classes (JP preedit mispositioning `#110202`, Arabic/RTL reversal `#110351`, CJK wrap artifacts `#98147`) — Unown's whole-code-point StdinBuffer and Intl.Segmenter word nav are the right bones; no new lane this round.

## 3. Adoption decisions — R1–R16, and the deliberate non-adoptions

- **R1 title states (adopt)**: `unown · <project> — working` / `— needs input` / `— done` written through the existing `setTitle` seam at the same lifecycle points CC's tab status fires (turn start/end, ask open/dismiss), restored to the static form when idle. Setting `terminalTitleStates` (default on) + `UNOWN_TERMINAL_TITLE_STATES=0`. OSC 7501 stays out (single-terminal dialect; OSC 0 is the portable lane).
- **R2 statusline (adopt, the fork's form)**: settings `statusLine: { command, refreshMs? }` (project-scope ignored like keybindings — a repo can't run commands in your bar), JSON payload on stdin with the fields Unown actually owns (session id/name, cwd + project, model id, effort/thinking level, permission mode, context-window used %, tokens in/out, turn count, queued-message count, version, uptime), stdout → ONE row above the quiet footer through the normal component pipeline (no raw writes; no whole-screen redraws — the flicker law), ANSI passthrough, 500 ms spawn timeout, refresh on turn end + `refreshMs` timer (min 1 s), max 2 lines, `UNOWN_STATUSLINE=0` kill. `/statusline` prints the active config + the payload contract + a copy-paste example script (the deterministic fork of CC's natural-language wizard — no metered model call for a config task). CC's "statusline hides footer hints" behavior is NOT adopted (the quiet footer's hints stay — the fork keeps discoverability).
- **R3 redraw (adopt)**: `/redraw` command + `app.redraw` action bound to `ctrl+alt+l` (ctrl+l stays the model selector — the round-1 fork move). Fullscreen: full repaint of the alt screen. Regular: re-render the live region from the anchor (the recovery CC promises, on the fork's key).
- **R4 external editor context (adopt)**: setting `externalEditorContext` (default off) — Ctrl+G prepends the last assistant reply as `# `-commented context above the prompt, strips the exact prepended block on save (byte-exact prefix bookkeeping; if the user deleted the block, nothing to strip).
- **R5 spinner amber (adopt)**: at ≥10 s of a working turn the elapsed chip and verb shift to the theme's warning color; back to normal on the next turn. One color decision on the existing 1 s tick — no new timers.
- **R6 paste-pill search (adopt)**: history entries gain an optional expansion field (`x`); submit records the marker text + the expanded text; the Ctrl+R overlay matches against the expansion and inserts the marker text; session scope keeps a parallel expansion map. Preview still shows the marker line.
- **R7 sanitization (adopt)**: a pure `sanitizeInvisible` strips zero-width (U+200B–200D, U+FEFF), bidi/isolate controls (U+202A–202E, U+2066–2069) and tag characters (U+E0000–U+E007F) from pasted content and from the submitted prompt; a dim notice names the count when stripping happened. Newlines/tabs/normal whitespace untouched.
- **R8 click-to-send (adopt)**: a click-region registry in TuiAltScreen — the app registers a screen-space row range + callback per render (no per-component hit-testing); the pending-messages hint strip registers its rows when the queue is non-empty and the click triggers the send-queued action. Release-commit semantics (2.1.311's lesson) at the region level.
- **R9 `/color` (adopt)**: `/color [red|blue|green|yellow|purple|orange|pink|cyan|default]`, session-scoped editor-border/accent override (the same seam the bash-mode border uses), no-arg lists colors + the active one. Not persisted — CC parity ("for the current session").
- **R10 `/keybindings` (adopt)**: opens `<agent-dir>/keybindings.json` in `$VISUAL`/`$EDITOR` through the same stop/start dance the transcript `v` lane uses, then reloads bindings (the `/reload` lane).
- **R11 `/tui` (adopt)**: `/tui [default|fullscreen]` switches live via a new optional `setTuiMode` on the extension UI API (vendored, non-breaking); no-arg prints the active renderer. Refuses when overlays are open (the existing switch guard).
- **R12 `/copy [N]` (adopt)**: extension override (the /settings precedent) — `/copy` copies the last assistant message (unchanged), `/copy 2` the second-latest; N>available lists what exists; the clipboard seam reuses pi's. The code-block picker and `w`-to-file stay out (the queue: our /export already writes files; the picker is a VS Code-panel pattern).
- **R13 notifications (adopt)**: a channel resolver — Ghostty/iTerm2/WezTerm (TERM_PROGRAM) get OSC 777 (`\x1b]777;notify;<title>;<body>\x07`), everything else keeps OSC 9 + BEL; `UNOWN_TUI_NOTIFY_CHANNEL=osc9|osc777|auto`. Plus a needs-input emission when a permission ask or questionnaire opens (immediate, distinct payload, `UNOWN_TUI_NOTIFY_INPUT=0` kill) — the "come back and answer" moment CC's tab badges signal.
- **R14 `/terminal-setup` (adopt, read-only fork)**: detects the terminal (TERM_PROGRAM/TERM) and prints the exact setup steps (Shift+Enter lanes, Option-as-Meta, clipboard, extended-keys, tmux config) with the applicable escape/URL. No file mutation — the safe fork; the doctor's terminal lane links here.
- **R15 keybinding validation (adopt)**: at keybindings.json load, a binding whose key string contains an unknown modifier token (`ctl+`, `cmd+` outside super, `option+`) or an unknown key name is ignored and reported (the load-time warning + doctor row). `parseKeyId` itself stays untouched (programmatic callers are trusted).
- **R16 refocus recap (adopt, local form)**: fullscreen focus events (the `?1004` lane already parsed) surface to the app; on refocus after ≥3 min away with ≥3 completed turns, a dim status line renders `back after N min · N turns · last: <80-char preview>`. NO model call — the metered-upstream fork; CC's generated one-liner is the roadmap form when an unmetered local lane exists.

**Deliberate non-adoptions, round 2 (reasons on record):**

- **Chord prefix layer (R18)** — CC's Ctrl+X chords, opencode's which-key, Amp's leader. The dispatch in the vendored TUI is federated (editor keys, app keys, dialog keys, alt-screen viewport keys — four pipelines), `ctrl+x` is already `app.message.copy` (CC freed it by moving copy to ctrl+shift+c selection), and a chord layer needs a pending-key state + which-key surface across all four pipelines. That is a dedicated round's architecture, not a rider on this one. Filed as the follow-up design note in §4.
- **Vim editor (re-affirmed round 1)** — the new evidence (Codex ships full emulation; CC keeps investing — 2.1.314 fixed four motion bugs, 2.1.301 added `%`) strengthens the eventual case, and the round-1 reasoning stands: emacs-plus-rebind covers the 80% case; a mode layer on this editor is its own project.
- **Voice, spell check, emoji shortcodes, ghost text, Enter-queues (re-affirmed round 1)** — unchanged.
- **Focus view (re-deferred)** — CC ships `/focus` fullscreen-only; Unown's collapsed regular rendering + transcript mode already bracket the density range, and the fullscreen third mode is another rendering pipeline. Reassess when the transcript mode grows a filter lane.
- **OSC 7501 / tab icon badges** — single-vendor dialects (Rex, VS Code); the portable OSC 0 title (R1) + OSC 9;4 progress (already shipped) carry the same signal on every terminal.
- **Prompt suggestions (Tab-accept next-prompt)** — a metered model call per suggestion; the flights lane already teaches prompts without spending quota.
- **`/usage` f-key fixes, /release-notes picker, /powerup, /scroll-speed, /sandbox UI, screen reader mode, Code Mode** — each is either already served (unown doctor, /changelog, flights, settings hub, sandbox policy docs) or its own round (screen reader, Code Mode).
- **Diff source picker (R17 deferred)** — the checkpoint store can serve per-turn diffs, but the picker + panel interaction deserves its own lane with the checkpoint UI; `/diff`'s working-tree card stays honest this round.

## 4. Follow-up design notes (not this round)

- The diff source picker on the checkpoint store (R17): `/diff [checkpoint <id>|last]`, reusing the rewind picker's manifest diffs.
