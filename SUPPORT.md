# Support

Where to get help with Unown, in the order you should try it. There is no chat, forum, or mailing list — GitHub issues are the support channel.

| If you need... | Use |
|---|---|
| To get running (install, connect a model, first session) | [docs/quickstart.md](docs/quickstart.md) |
| A symptom fixed (errors, doctor reds, sandbox, stack boot) | [docs/troubleshooting.md](docs/troubleshooting.md) — symptom → cause → fix |
| Chat-path diagnostics | `unown doctor` — endpoint reachability, bridge upstream key/health, model routability |
| Command, flag and slash-command reference | [docs/usage.md](docs/usage.md) |
| Memory, providers, configuration | [docs/memory.md](docs/memory.md) · [docs/providers.md](docs/providers.md) · [docs/configuration.md](docs/configuration.md) |
| Platform specifics | [docs/windows.md](docs/windows.md) · [docs/macos.md](docs/macos.md) |
| To report a bug | [GitHub issues](https://github.com/kanishka-namdeo/Unown/issues) — the bug form (version, OS, setup method, logs from `.run/*.log`) |
| To propose a feature | [GitHub issues](https://github.com/kanishka-namdeo/Unown/issues) — the feature form |
| To contribute code or docs | [CONTRIBUTING.md](CONTRIBUTING.md) |
| To report a security vulnerability | [SECURITY.md](SECURITY.md) — private disclosure only, never a public issue |

Bug reports that name a specific commit and paste the relevant `.run/*.log` lines (secrets removed) get fixed fastest — see the bug form. Everything else, including code of conduct reports, goes through GitHub issues.
